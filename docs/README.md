# docs

수업 제출용 문서·발표·시연 자료를 보관하는 폴더입니다.

## 하위 폴더

| 폴더 | 내용 |
|------|------|
| `report/` | 프로젝트 레포트 (PDF 권장) |
| `presentation/` | 발표자료 PPT |
| `demo/` | 시연 동영상 |

## 제출 전 체크리스트

- [ ] 레포트: ERD, 스키마 설명, 쿼리/뷰/인덱스 설계 근거, 화면·기능 설명
- [ ] PPT: 주제, 팀원, 시스템 개요, 데모 시나리오
- [ ] 동영상: 주요 기능 시연 (예약, 조회, 체크인 등)

대용량 파일(PPT, MP4)은 `.gitignore`에 포함되어 있을 수 있습니다. Git LFS 또는 외부 링크(Google Drive 등)로 제출 방식을 팀에서 정하세요.
