# lib

JDBC 드라이버 등 **외부 JAR** 라이브러리를 두는 폴더입니다.

## MySQL Connector/J

1. [MySQL Connector/J](https://dev.mysql.com/downloads/connector/j/) 에서 JAR 다운로드
2. 이 폴더에 `mysql-connector-j-8.x.x.jar` 저장
3. IDE 또는 `javac -cp` / `java -cp` 에서 classpath에 추가

> JAR 파일은 용량·라이선스 정책에 따라 Git에 포함하지 않을 수 있습니다. 팀원 간 공유 방법을 README 최상위 실행 방법에 적어 두세요.
