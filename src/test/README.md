# Test Package

## 역할

`test` 패키지는 구현한 기능이 정상적으로 동작하는지 확인하기 위한 테스트용 클래스

정식 UI가 완성되기 전에도 Service와 DAO 기능을 직접 실행하여 백엔드 로직을 검증하기 위해

## 주요 클래스

### ReservationTest

예약 기능 테스트를 담당

테스트 항목:
- 예약 ID 조회
- 중복 예약 방지
- 정상 예약 생성
- 예약 취소
- 완료된 예약 취소 방지
- 상담 시간대 예약 가능 여부 확인

## 실행 방법

1. `create.sql`을 root 권한으로 실행하여 DB를 초기화
2. `ReservationTest` 클래스를 실행한다.
3. 콘솔 출력 결과를 확인

## 참고
테스트 코드는 실제 DB 데이터를 삽입하고 수정한다. 반복 테스트 전에는 `create.sql`을 다시 실행하여 DB를 초기화하는 것이 좋다.
